# 🔐 Integrity Verification and Data Security in Wireless Sensor Networks

## 📌 Project Overview
This project focuses on ensuring **data security** and **integrity verification** in Wireless Sensor Networks (WSNs). WSNs are widely used in applications such as environmental monitoring, smart cities, healthcare, and military systems.

Due to their open and distributed nature, WSNs are vulnerable to attacks like data tampering and interception. This project provides a secure framework using:
- **Homomorphic Encryption** for data security
- **Chaotic Technique & HMAC** for data integrity verification

---

## 🎯 Objectives
- Ensure **secure data transmission**
- Detect **data tampering**
- Maintain **data integrity and confidentiality**
- Provide **efficient and scalable security mechanisms**

## 🏗️ System Architecture
The system consists of three main components:
1. **Sender**
   - Encrypts data using homomorphic encryption
   - Generates integrity verification code (HMAC)

2. **Receiver**
   - Decrypts received data
   - Regenerates integrity code and verifies authenticity

3. **Network Simulation**
   - Simulates WSN nodes and communication paths

---

## 🔄 Workflow
1. Generate network nodes  
2. Select source and destination  
3. Enter message  
4. Encrypt message  
5. Generate integrity code  
6. Send data  
7. Receiver decrypts data  
8. Verify integrity  
9. Send acknowledgement
